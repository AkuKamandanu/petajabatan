    Tambah Jabatan

    Mengatur bagaimana jabatan ini sendiri ditampilkan di antara saudara-saudaranya (jabatan lain dengan atasan yang sama) — diatur dari sini, bukan dari atasannya. Sebagian saudara bisa berbaris sementara yang lain bertumpuk, sekaligus dalam satu bagan.

    Jabatan dengan kategori ini akan dikelompokkan bersama jabatan sejenis dalam satu kotak terpisah di bawah atasannya, bukan sebagai kotak individual di bagan utama.

    Ini mengatur susunan bawaan untuk anak-anak dari jabatan ini. Anak yang sudah punya pengaturan "Susunan Sendiri" (di formulirnya masing-masing) akan tetap memakai pengaturannya sendiri, mengabaikan ini.

    Pengaturan Sinkronisasi GitHub

    Data akan dibaca/ditulis sebagai berkas .xlsx di repositori GitHub Anda melalui GitHub API, langsung dari peramban — tidak perlu server tambahan.

    ⚠ Token disimpan hanya di penyimpanan lokal peramban ini (localStorage), tidak pernah dikirim ke pihak lain selain api.github.com. Gunakan token fine-grained yang dibatasi hanya untuk repositori ini, dan jangan pakai perangkat/peramban bersama untuk menyimpannya.
